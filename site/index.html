3-Tier Scalable System Architecture

Decoupled presentation, business logic, and document persistence tiers engineered for rapid 48-hour hackathon demand surges.

Client Single-Page App

Built on React 19 and Tailwind CSS v4, compiled with Vite. Delivers reactive Kanban boards, requirement filter switches, and real-time telemetry state.

02 // Core Algorithm & Sandbox

Heuristic Matching Engine Formulation

TeamSync avoids opaque black-box machine learning in favor of an explainable, deterministic weighted-overlap composite formulation. Adjust parameters below to compute synergy live:

S(u, L) = w₁·C(u, L) + w₂·O(u, L) + w₃·G(u) + w₄·A(u)
1. Skill Complementarity Overlap (w₁ = 45%) 1.00
Overlap between candidate tech stack and open project role
2. Domain Interest Alignment (w₂ = 20%) 0.85
Interest match (e.g. Fintech, Healthcare AI, Web3, EdTech)
3. GitHub Telemetry Activity (w₃ = 20%) 0.90
Verified commit frequency, repo stars, and language proof
4. Hackathon Sprint Availability (w₄ = 15%) 1.00
Active 48h bandwidth confirmation

03 // Lifecycle

4-Stage Team Formation Workflow

Collegiate Verification

GitHub Proof-of-Work

GitHub handle linkage extracts public commits, active repositories, and programming language distributions.

Synergy Match Scoring

Open hackathon listings trigger matching formulation S(u, L), ranking candidates by skill complementarity.

Sprint Kanban Board

Mutual connection handshake unlocks private coordination chat, task boards, and milestone tracking.
