01 // Problem & Solution

Why TeamSync Exists

Hackathons demand multidisciplinary skills — AI/ML, UI/UX, Web3, Backend. Yet teammate search remains broken across WhatsApp, batch Discord groups, and word-of-mouth.

Verified Campus Auth

Registrations strictly restricted to verified college email domains (@thapar.edu). Zero anonymous trolls, zero ghosting.

GitHub Proof-of-Work

Profiles pull verified public repositories, commit activity, and top language telemetry directly via GitHub API callbacks.

Complementary Matching

Transparent weighted-overlap formulation calculates synergy rather than plain keyword overlap: Skills + Domain + GitHub + Hours.

Hackathon Workspace

Once connected, squads unlock an integrated Kanban board, milestone trackers, and deadline coordinator for the 48-hour build.

03 // Execution Pipeline

How Team Formation Works

From identity verification to confirmed hackathon squads in 4 structured stages.

01

Domain Sign-Up

Student enters @thapar.edu credentials. System verifies institutional token and initializes profile.

02

Link Proof-of-Work

Student links GitHub handle. System parses public repos, commit frequency, and top tech stacks into structured signals.

03

Heuristic Match

When a hackathon listing is posted, the engine calculates complementary overlap: S(u, L) ∈ [0, 1] and ranks candidates.

04

Squad Workspace

Mutual connection handshake unlocks private coordination chat and a shared Kanban board for task allocation during the build.

04 // Engineering Foundation

System Architecture & Tech Stack

A clean 3-tier architecture ensuring low latency, stateless horizontal scalability, and verified telemetry.

Tier 1: Client Layer

Responsive single-page application built with React 19 and Tailwind CSS v4. Features fast Vite bundling, reactive Kanban views, and accessible design.

React 19 Tailwind v4 Vite 8 Lucide Icons

Tier 2: API & Logic Gateway

RESTful backend engineered on Node.js & Express. Features stateless JWT authentication, regex college domain filters, and heuristic score computation.

Node.js LTS Express.js JWT Auth Socket.io

Tier 3: Data & Cloud

Managed MongoDB Atlas document store with Mongoose ODM schemas. Compound multi-key indexes on skill arrays and college domains guarantee sub-200ms queries.

MongoDB Atlas Mongoose ODM B-Tree Index GitHub Actions
